# QUBO — эвристический решатель

Быстрый эвристический решатель задачи **QUBO (Quadratic Unconstrained Binary
Optimization)** — минимизации квадратичной формы xᵀQx по бинарному вектору
x ∈ {0,1}ⁿ. Задачи QUBO лежат в основе множества комбинаторных задач и моделей
квантового/адиабатического отжига.

## Как работает

1. Релаксация: непрерывный вектор обновляется короткими шагами градиентного типа
   (`x ← clip(x − η·Qx, −1, 1)`), 50 итераций
2. Бинаризация по знаку (`x > 0`)
3. Один проход локального улучшения: пробные перевороты бит, снижающие энергию
   `xᵀQx`

Акцент на скорости — алгоритм рассчитан на быстрый приближённый ответ.
